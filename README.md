## Template engine
`template/gods_grace_reference.html` is the reusable HTML/CSS document template
(navy #062B60, deep blue #003F91, gold #E5AD22, light rows #EAF2FA), rendered to a
real text PDF with Playwright + Chromium: A4, repeated table header, gold page footer.

To render: open the HTML in Chromium via Playwright and call page.pdf() with
print_background, display_header_footer and the navy footer template.
